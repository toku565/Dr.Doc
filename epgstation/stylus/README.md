# EPGStation Stylus CSS

EPGStation の番組表・録画一覧が見づらかったため、
個人利用向けに Stylus 用の CSS を作成しました。

## 対象環境
- EPGStation（検証時バージョン:v2.10.0）
- Stylus（Firefox / Chrome）

## 主な変更点
- 番組タイトルの折り返し表示（見切れ防止）
- 行間・余白の調整による情報密度向上
- 一覧表示時の視認性改善

## 使い方
1. ブラウザに Stylus をインストール
2. 新しいスタイルを作成
3. `epgstation.user.css` の内容を貼り付け
4. 対象URLに EPGStation の URL を指定

## 注意
- 個人利用前提で作成しています
- EPGStation のアップデートで動作しなくなる可能性があります
- サポートは行いません（自己責任でどうぞ）
